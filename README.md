# ESP-v2: Умная подсветка лестницы на ESP32 (ESP-IDF v5)

Прошивка и интерфейс управления умной светодиодной подсветкой ступеней лестницы на микроконтроллере ESP32 с адресной светодиодной лентой (WS2812B/WS2811/SK6812), датчиками движения (HC-SR04 / PIR) и веб-интерфейсом управления.

---

## 📥 Файлы прошивки (GitHub Releases)

В разделе [GitHub Releases](https://github.com/geminibitok-oss/ESP-v2/releases/latest) доступны готовые скомпилированные бинарники:

| Файл | Назначение | Адрес во Flash (Offset) |
| :--- | :--- | :---: |
| **`firmware_merged.bin`** (~940 КБ) | **Единый файл "все-в-одному"** (рекомендуется) | **`0x0`** |
| **`bootloader.bin`** (~26 КБ) | Вторичный загрузчик ESP32 | **`0x1000`** |
| **`partition-table.bin`** (~3 КБ) | Таблица разделов флеш-памяти | **`0x8000`** |
| **`ESP_lestn_v2.bin`** (~880 КБ) | Основная прошивка (или для Wi-Fi OTA) | **`0x10000`** |
| **`flasher_args.json`** | Аргументы и адреса для esptool | — |

## 🛠 Варианты прошивки ESP32

### 🧩 Вариант 2. Раздельная прошивка (3 файла прямо со страницы GitHub Releases)

Используйте этот вариант, если вы скачали 3 отдельных файла из раздела Releases / Assets:
* `bootloader.bin`
* `partition-table.bin`
* `ESP_lestn_v2.bin`

#### Таблица адресов Flash:
* `0x1000` ➔ `bootloader.bin`
* `0x8000` ➔ `partition-table.bin`
* `0x10000` ➔ `ESP_lestn_v2.bin`

#### Способ 1. Через браузер (Espressif Web Flasher)
1. Откройте в Chrome, Edge или Opera: **[https://espressif.github.io/esptool-js/](https://espressif.github.io/esptool-js/)**
2. В поле **Baudrate** установите **`460800`** (или `115200` при помехах на линии). Не используйте 921600.
3. Нажмите **Connect** и выберите COM-порт вашего контроллера ESP32.
   *(Если плата не входит в режим загрузки, удерживайте кнопку **BOOT (IO0)** на плате 2 секунды).*
4. В таблице файлов добавьте 3 строки (кнопка `Add File`):
   * **Строка 1:** Адрес **`0x1000`** ➔ выберите файл **`bootloader.bin`**
   * **Строка 2:** Адрес **`0x8000`** ➔ выберите файл **`partition-table.bin`**
   * **Строка 3:** Адрес **`0x10000`** ➔ выберите файл **`ESP_lestn_v2.bin`**
5. Нажмите кнопку **Program**.
6. По завершении нажмите кнопку **EN / RESET** на плате ESP32 (или переподключите USB).
7. Контроллер поднимет собственную сеть Wi-Fi: **`ESP-Stairs-AP`** (пароль `12345678`).

#### Способ 2. Через командную строку (esptool.py)
Положите 3 скачанных файла в одну папку:

* **Windows (PowerShell или CMD):**
  ```bash
  esptool.py --chip esp32 -p COM3 -b 460800 write_flash 0x1000 bootloader.bin 0x8000 partition-table.bin 0x10000 ESP_lestn_v2.bin
  ```
  *(Замените `COM3` на номер вашего порта в Диспетчере устройств)*

* **Linux / macOS:**
  ```bash
  esptool.py --chip esp32 -p /dev/ttyUSB0 -b 460800 write_flash 0x1000 bootloader.bin 0x8000 partition-table.bin 0x10000 ESP_lestn_v2.bin
  ```

### ⚡ Вариант 1. Прошивка единым файлом firmware_merged.bin (Быстрый старт)

* Скачайте файл **`firmware_merged.bin`**.
* В онлайн-прошивальщике [esptool-js](https://espressif.github.io/esptool-js/) укажите только одну строку:
  * Адрес: **`0x0`** ➔ файл: **`firmware_merged.bin`**
* Или через терминал:
  ```bash
  esptool.py --chip esp32 -p COM3 -b 460800 write_flash 0x0 firmware_merged.bin
  ```

---

### 🌐 Вариант 3. Обновление по воздуху (Wi-Fi OTA)

Если плата уже прошита и подключена:
1. Подключитесь к сети `ESP-Stairs-AP` (или перейдите по локальному IP платы в вашей домашней сети).
2. В веб-интерфейсе откройте раздел **«Обновление ПО (OTA)»** (адрес `http://192.168.4.1/ota`).
3. Загрузите файл **`ESP_lestn_v2.bin`** и нажмите **«Начать OTA обновление»**.

## ❓ Решение частых вопросов

* **Ошибка `Possible serial noise or corruption` при записи:**
  Возникает при установке скорости 921600. Уменьшите скорость Baudrate до **`460800`** или **`115200`**.
* **Плата зависает на `Connecting...`:**
  Удерживайте кнопку **BOOT** (IO0) на ESP32 во время нажатия Connect / Program, пока не начнется запись.
* **Ошибка `Header fields are too long` в браузере:**
  Возникает при переполненных заголовках cookies от других локальных сайтов. Очистите кэш и cookies для `192.168.4.1` или откройте страницу в режиме Инкогнито.

## 🔄 Обновление с GitHub Releases и ротация версий

1. **Проверка версий и выбор релиза**:
   - В веб-интерфейсе (вкладка **«Обновление по Wi-Fi (OTA)»** или страница **«Обновление (OTA)»** веб-сервера контроллера) встроен модуль автоматической сверки текущей версии на чипе со списком доступных релизов из GitHub API.
   - Пользователь видит список всех доступных версий (`latest`, теги `vX.Y.Z`), дату сборки и статус обновления.
   - Можно в 1 клик выбрать любую версию и нажать **«Установить версию [X] на ESP32»** (прошивается файл `ESP_lestn_v2.bin` по воздуху через HTTP POST `/api/ota`).

2. **Ограничение не более 10 релизов на GitHub**:
   - В пайплайн `.github/workflows/build-firmware.yml` встроен автоматический шаг ротации: после сборки скрипт проверяет количество релизов, сортирует их по дате публикации и безвозвратно удаляет самые старые, оставляя **ровно 10 самых свежих версий**.
   - Дополнительно в веб-интерфейсе доступна кнопка **«Ротация (max 10)»** для ручной очистки старых релизов при наличии Personal Access Token.

## 📟 Просмотр IP-адреса Wi-Fi через UART (Serial порт)

При включении контроллера, подключении к роутеру, а также в периодическом heartbeat-логе (каждые 10 сек) ESP32 выводит в UART порт свой IP-адрес:
```text
===================================================
 [UART / WI-FI] ESP32 ПОЛУЧИЛ IP-АДРЕС В СЕТИ:
 >>>  IP: 192.168.1.145  <<<
 Веб-интерфейс доступен по ссылке: http://192.168.1.145
 OTA-обновление: http://192.168.1.145/update
===================================================
```

### Команды запуска монитора UART в Windows:

1. **Самый простой способ (через Python miniterm)**:
   ```cmd
   python -m serial.tools.miniterm COM3 115200
   ```
   *(Замените `COM3` на номер вашего порта в «Диспетчере устройств» Windows).*  
   *Для выхода нажмите `Ctrl + ]`.*

2. **Через ESP-IDF монитор**:
   ```cmd
   idf.py -p COM3 monitor
   ```
   *Для выхода нажмите `Ctrl + ]`.*

3. **Через PuTTY**:
   - Connection type: **Serial**
   - Serial line: **COM3**
   - Speed: **115200**
   - Нажмите **Open**

4. **Прямо в браузере (без установки программ)**:
   - Откройте вкладку **«USB Прошивка и Serial»** в веб-интерфейсе
   - Нажмите **«Подключить ESP32 по USB»**
   - В окне **Serial Monitor** сразу отобразится IP-адрес и лог работы.
